A Python program that writes one original one-line joke about office life — automating your job only to spend all day in meetings explaining the automation — to `/output/entry.txt` (123 characters, single line, UTF-8).

## The joke

> I automated my job with a script, and now I spend eight hours a day in meetings explaining to my boss how the script works.

`main.py` asserts the joke is a single line of 1–200 characters before writing it, and verifies the written file round-trips inside those limits.

## Run it

```sh
python3 main.py
```
